Math with Pip, an AI math tutor for kids

Children aged 6–10 solve math problems while Pip, an AI tutor, coaches them with questions and hints instead of answers. A flashcard mode offers quick practice without the AI.

  • The AI coaches and code grades: a Java checker marks every answer, so the model can't leak an answer or mark a wrong one right.
  • Agent tool calling with Spring AI, with each tool scoped to the child's own session on the server.
  • No accounts and no personal data, with the API key kept in Secret Manager.
  • Java 21
  • Spring Boot 4
  • Spring AI
  • Claude
  • React
  • Docker
  • Cloud Run
  • Firebase Hosting
